# 문항 데이터 스키마

모든 문항 데이터는 `data/*.js` 파일에 들어 있습니다. 앱은 `file://`로 열어도 동작해야 하므로 fetch를 쓰지 않습니다. 대신 `<script>` 태그로 불러온 파일이 전역 레지스트리 `HMAT`에 데이터를 등록합니다.

```js
// data/set1-verbal.js
HMAT.add(1, 'verbal', [ /* Item, ... */ ]);
// data/set1-diagram.js
HMAT.add(1, 'diagram', { rules: Rules, items: [ /* Item */ ] });
// data/personality-bank.js
HMAT.addPersonalityBank([ /* Statement */ ]);
```

## 영역 키

| 키 | 영역 | 문항 | 시간 | 비고 |
|---|---|---|---|---|
| `verbal` | 언어이해 | 15 | 20분 | 5지선다 |
| `logic` | 논리판단 | 10 | 15분 | 5지선다 |
| `data` | 정보추론(자료해석) | 15 | 20분 | 5지선다 |
| `diagram` | 도식이해 | 8 | 12분 (+규칙 숙지 4분) | 하반기형 |
| `spatial` | 공간지각 | 10 | 15분 | 상반기형 |

## Item (적성 문항)

```js
{
  id: 'S1-VE-01',            // 회차-영역-번호. 영역 약어: VE, LO, DA, DI, SP
  subtype: '세부내용 일치',     // 하위유형 이름. 결과 화면에서 유형별 정답률을 낼 때 쓴다.
  group: {                   // 선택. 여러 문항이 지문이나 자료를 함께 쓸 때 넣는다.
    id: 'G1',                // 같은 회차, 같은 영역 안에서 고유해야 한다.
    label: '[3~4] 다음 글을 읽고 물음에 답하시오.'
  },                         // 같은 group에 속한 문항은 passage와 materials가 완전히 같아야 한다.
  passageTitle: '...',       // 선택
  passage: '...',            // 선택. 문단 사이는 "\n\n"으로 구분한다.
                             // 쓸 수 있는 인라인 태그는 <b> <u> <br> <sup> <sub>뿐이다.
                             // 빈칸은 '( ㉠ )' 또는 '(    )'로 쓴다.
                             // 문단 배열 문항에서는 문단 앞에 '(가) ', '(나) '를 붙인다.
  materials: [ Material ],   // 선택. 표, 그래프, 보도자료 같은 자료
  stem: '다음 글의 내용과 일치하지 않는 것은?',   // 발문
  box: { title: '보기', items: ['ㄱ. ...', 'ㄴ. ...'] },   // 선택. <보기>나 <조건> 상자
  figure: { svg: '<svg ...>...</svg>', caption: '' },   // 선택. 코드로 생성한 그림
  choices: ['...', '...', '...', '...', '...'],   // 선지 5개. 번호 ①~⑤는 붙이지 않는다.
  choiceCharts: [ ChartSpec x5 ],   // 선택. 선지가 그래프일 때 쓰며, 이때 choices는 생략한다.
  choiceSvgs: [ '<svg>' x5 ],       // 선택. 선지가 생성된 그림일 때 쓰며, 이때 choices는 생략한다.
  answer: 3,                 // 정답 번호(1~5)
  explanation: '...'         // 해설. 왜 정답인지와 주요 오답이 왜 틀렸는지 설명한다. 인라인 태그를 쓸 수 있다.
}
```

## Material

```js
{ kind: 'table', title: '<표> 연도별 친환경차 판매량', unit: '단위: 천 대',
  columns: ['구분', '2022', '2023', '2024'],
  rows: [['전기차', 120, 150, 180], ['수소차', 10, 12, 9]],
  note: '※ 친환경차 = 전기차 + 수소차 + 하이브리드' }

{ kind: 'chart', type: 'bar' | 'line' | 'hbar' | 'pie' | 'stacked',
  title: '<그림> 지역별 충전기 수', unit: '단위: 기',
  categories: ['서울', '경기', '부산'],
  series: [ { name: '급속', values: [10, 20, 5] },
            { name: '비율', values: [..], as: 'line', axis: 'right', unit: '%' } ],  // bar 위에 겹쳐 그리는 선 그래프(이중축)
  note: '' }
// pie 차트는 series 1개만 쓴다. values는 비율이나 값이다.

{ kind: 'text', title: '<보도자료>', body: '문단\n\n문단' }
```

## 도식이해 Rules

```js
{
  title: '도식 규칙',
  intro: '각 기호는 다음과 같은 규칙에 따라 문자열을 변환한다.',
  symbols: [ { key: 'A', svg: '<svg ...>', name: '검은 별', desc: '첫째와 둘째 자리를 바꾼다.', example: 'ABCD → BACD' } ],
  note: '※ 알파벳 다음 순서는 Z 다음에 A로 순환한다.'
}
```

## Statement (인성 진술문)

```js
{ id: 'P001', text: '나는 계획을 세운 뒤에 일을 시작하는 편이다.',
  dim: 'C',          // C=성실·계획, E=외향·주도, N=정서안정, O=개방·도전, A=협력·친화, I=윤리·책임
  key: 1,            // 1이면 정문항(그렇다일수록 해당 특성이 높음), -1이면 역문항
  pair: 'C07',       // 선택. 일관성 쌍 ID. 같은 ID를 가진 두 문항은 같은 내용을 묻는다(key가 다를 수 있다).
  lie: false }       // true이면 사회적 바람직성(과장 응답) 탐지 문항이다.
                     // 예: '나는 살면서 한 번도 거짓말을 한 적이 없다.'
```

## 작성 원칙

- 모든 문항은 새로 작성합니다. 기출복원 문항이나 시판 교재 문항을 그대로 옮기거나 바꿔 써서는 안 됩니다.
- 정답 번호는 한 영역 안에서 ①~⑤가 고르게 나오도록 배분합니다. 15문항이면 번호마다 3개, 10문항이면 2개, 8문항이면 1~2개입니다.
- 계산 문항은 계산기 없이 어림셈으로 풀 수 있게 만듭니다. 정답 수치는 반드시 코드로 검산합니다.
- 논리 문항은 정답이 하나뿐이어야 합니다. 브루트포스로 확인합니다.
