# 현대자동차 HMAT 대비 모의고사 3회분 제작 사양서 (비공식, 2026-10-07 기준)

## 0. 근거 수준과 표기법
- 조사 에이전트 6개 모두 원문 페이지를 열지 못했습니다. WebFetch가 egress 프록시에 막혔기 때문입니다. 그래서 이 사양의 근거는 전부 검색 스니펫과 검색엔진 요약입니다. 모순을 풀려고 이번 단계에서 다시 검색했지만 턴 단위 검색 한도(200회)가 이미 소진되어 실행되지 않았습니다.
- 신뢰도 표기
  - **[상]** 공식 보도 또는 여러 독립 출처
  - **[중]** 응시 후기 여러 건, 또는 상세 후기에 교재·가이드가 일치하는 경우
  - **[하]** 단일 출처, 서로 충돌하는 출처, 일반 관행에서 추정한 경우
  - **[모의]** 실제 근거 없이 모의고사 편의를 위해 정한 값
- 연도 표기는 근거가 된 회차입니다(예: 2025H2 = 2025 하반기).

## 1. 대상 시험 정의
| 항목 | 결정 | 근거 |
|---|---|---|
| 대상 | 현대자동차 **대졸 신입** 온라인 HMAT. 연구개발·디자인·생산/제조·사업/기획·경영지원·IT 공통 | 공식 전형: 서류 → 인적성검사 → 직무면접 → 종합면접 → 채용검진 [상, 2025H2~2026H2] |
| 구성 | **적성검사**(지정 일시, 원격 감독)와 **인성검사**(별도 기간 응시, 카메라 없음)를 각각 별도 세션으로 구성 | [중, 2025H2] |
| 기본 형식 | **하반기형**. 언어이해, 논리판단, 정보추론(자료해석), 도식이해 4영역 | 문항 수와 시간을 영역별로 적은 상세 후기가 있는 유일한 회차 [중, 2025H2]. 상반기는 공간지각, 하반기는 도식이해로 번갈아 출제되는 패턴 [중, 2013~2026] |
| 대체 형식 | **상반기형**. 도식이해 자리에 공간지각을 넣음(선택 가능) | [하, 2026상반기, 2026-05-02 시행 후기와 시대에듀 2026 하반기판 목차] |
| 제외 | 생산직(모빌리티 기술인력)은 오프라인 지필 OMR이라 형식이 다름. R&D 전공시험, 경력직, 역사에세이(2018 상반기 폐지 [상]), AI역량검사(2023H2까지), 계열사 시험도 제외 | |

기본 형식을 하반기형으로 정한 이유는 셋입니다. 2026 하반기 시험이 지금 진행 중이거나 곧 열립니다. 하반기에는 도식이해가 나오는 패턴이 이어져 왔습니다. 영역별 수치가 확인된 회차는 2025H2뿐입니다. 2026H2 후기가 나오면 다시 검증해야 합니다.

## 2. 적성검사 구조 (3개 회차 공통)
| 순서 | 영역 | 문항 | 제한시간 | 선지 | 신뢰도 |
|---|---|---|---|---|---|
| 1 | 언어이해 | 15 | 20분 | 5지 ①~⑤ | 문항·시간 [중, 2025H2]. "20문항"이라는 보고도 있음 [하] → 설정값 |
| 2 | 논리판단 | 10 | 15분 | 5지 | [중, 2025H2] |
| 3 | 정보추론(자료해석형) | 15 | 20분 | 5지 | [중, 2025H2] |
| 4 | 도식이해 | 규칙 숙지 **4분** + 8문항 | 12분 | 5지 | [중, 2025H2, 단일 상세 후기] |
| 4' | 공간지각 (상반기형 대체) | 10 | 15분 | 5지 | 문항 [하, 2026상반기], 시간 [모의] (총 77분 보고에서 역산) |
| 합계 | | 48 | 67분 (+준비 4분 = 71분) | | 가이드의 "50문항/65분"과 대체로 맞음. 체크인을 포함한 총 소요는 77~80분으로 보고됨 |

- 5지선다는 과거 HMAT와 교재의 관행입니다. 2025H2 온라인 시험에서 직접 확인한 것은 아닙니다 [중].
- 영역 순서는 후기에 나열된 순서를 따랐습니다 [하].
- 영역마다 타이머가 따로 돌고 시간이 공유되지 않습니다. 영역 안에서는 문항을 자유롭게 오가지만 끝난 영역으로는 돌아갈 수 없습니다 [중, 2025H2~2026상반기].
- 채점은 정답 수 기준이고 오답 감점은 없습니다. 영역별 과락이 있다는 말이 있습니다. 둘 다 멘토 답변일 뿐 공식 확인은 없습니다 [하].

## 3. 회차별 하위유형 배분 (회차마다 같은 배분, 소재와 형태는 다르게)

### 3-1. 언어이해 (15문항/20분)
| 하위유형 | 문항 |
|---|---|
| 세부내용 일치/불일치 | 5 |
| 추론 가능/불가 | 3 |
| 주제·제목·중심내용 | 2 |
| 문단 배열 | 2 |
| 빈칸 완성 | 2 |
| 비판·반박 또는 개요·보고서 수정 | 1 |
- 지문은 600~1,000자의 설명문이나 논설문입니다. 기본은 지문 1개에 1문항이고, 지문 1개에 2문항을 묶은 세트를 회차당 1개까지 허용합니다. 선지는 지문의 단어 하나를 슬쩍 바꾼 함정형으로 만듭니다(후기에서 언급, [하]). 난이도는 GSAT·SKCT 언어 영역과 같거나 약간 어렵게 맞춥니다(후기 평가, [하]).
- 회차당 주제 배분: 과학기술 6(그중 모빌리티·에너지 3~4), 경제·경영 3, 사회·제도 3, 인문 3.
  - 1회 모빌리티 소재: 배터리 열관리, 수소연료전지, SDV/OTA
  - 2회: 전고체 배터리, 센서 퓨전 자율주행, 탄소국경조정
  - 3회: UAM, 로보틱스, 회생제동, 공급망 재편

### 3-2. 논리판단 (10문항/15분)
| 하위유형 | 문항 |
|---|---|
| 명제·삼단논법(결론 또는 빠진 전제 찾기) | 3 |
| 조건추리(배치·순서·대응; 요일, 층, 부서, 시험주행 일정) | 4 |
| 참·거짓 진술(거짓말하는 사람 1~2명) | 2 |
| 경우의 수·논리 퍼즐 | 1 |
- 모든 퍼즐은 답이 하나뿐인지 검증 스크립트로 확인해야 합니다.

### 3-3. 정보추론/자료해석 (15문항/20분)
| 하위유형 | 문항 |
|---|---|
| 자료와 일치하는 것/일치하지 않는 것 | 6 |
| 수치 계산(증감률, 비중, 비율, 차이) | 4 |
| 표를 그래프로 변환(올바른 그래프 고르기) | 2 |
| 여러 자료와 조건을 결합한 추론(보도자료·보고서형, 옛 정보추론 성격) | 3 |
- 자료 1세트에 2문항을 묶은 세트를 회차당 3~4개 넣습니다. 수치는 계산기 없이 어림셈으로 풀리도록 설계합니다. 기본 설정에서 계산기를 제공하지 않기 때문입니다. 후기에서는 이 영역이 교재보다 복잡했다고 평가했습니다 [하, 2025H2·2026상반기].
- 소재: 지역별 판매, 생산·수출, 친환경차 비중, 충전 인프라, 설문, 원가.

### 3-4. 도식이해 (규칙 숙지 4분 + 8문항/12분)
- 회차마다 규칙표 1장을 둡니다. 기호 4~6개가 각각 하나의 변환을 뜻합니다. 규칙표는 숙지 화면에서 먼저 보여 줍니다.
| 하위유형 | 문항 |
|---|---|
| 순방향: 입력 → 기호 연쇄 → 출력 | 4 |
| 빠진 기호 추론: 입력과 출력이 주어짐 | 2 |
| 역방향: 출력에서 입력 추론 | 1 |
| 조건 분기·비교 기호 포함 | 1 |
- 문항은 쉬운 것부터 어려운 순서로 배치합니다(후기 [하]).
- 2025H2의 실제 소재가 문자열인지 도형인지 3×3 배열인지는 확인되지 않았습니다. 그래서 회차마다 소재를 다르게 해서 위험을 분산합니다 [하].
  - 1회: 4칸 문자·숫자열 변환
  - 2회: 3×3 도형 격자 변환(행·열 교환, 회전, 색 반전)
  - 3회: 도형 격자에 조건 스위치를 섞은 혼합형

### 3-5. 공간지각 (상반기형 대체 모듈, 10문항/15분)
| 하위유형 | 문항 |
|---|---|
| 투상도(정면·우측면·평면)를 보고 맞는 입체 블록 고르기 | 4 |
| 입체를 보고 맞는(또는 틀린) 투상도 고르기 | 2 |
| 전개도를 접은 입체 | 2 |
| 종이를 접고 구멍을 뚫은 뒤 펼친 모양 | 1 |
| 블록 개수·회전 | 1 |
- 투상도에서 입체를 고르는 유형은 2026상반기 후기에 나왔고 시간이 많이 걸렸다고 합니다 [중].
- 그림은 SVG 등각투상으로 직접 그립니다.

## 4. 인성검사 (회차당 1세트, 적성과 별도 세션)
| 파트 | 구성 | 응답 | 신뢰도 |
|---|---|---|---|
| 인성Ⅰ | 진술문 3개를 한 묶음으로 제시. 보고된 문항 수는 155인데 3으로 나누어떨어지지 않아, **52묶음 156진술**로 구현 | 진술마다 **7점** 리커트(전혀 아니다~매우 그렇다; 설정에서 5점으로 변경 가능). 묶음마다 **가깝다(가) 1개, 멀다(멀) 1개**를 고르고, 같은 진술을 둘 다로 고를 수 없음 | 묶음과 가/멀 방식 [중], 척도 점수 [하] (5점과 7점 보고가 충돌) |
| 인성Ⅱ | 단문 진술 300개 | 기본은 **예/아니오 2지**(설정에서 4점·5점으로 변경 가능) | [하] |
| 시간 | Ⅰ과 Ⅱ를 합쳐 **110분** 공유 타이머. 시간이 끝나면 자동 종료 | 대체 설정: Ⅰ 50분 + Ⅱ 45분 [하] | [중, 2023~2026 가이드 여러 건] |
| 페이지 제한 | Ⅰ은 페이지당 3묶음에 150초, Ⅱ는 페이지당 10문항에 60초. 시간이 지나면 미응답인 채로 다음 페이지로 넘어감 | "3세트(페이지)마다 시간 제한이 있고 매우 촉박하다"는 후기는 있지만 초 단위 값은 [모의] | [하] |
| 이동 | 이전 페이지로 돌아갈 수 없음 | "읽고 체크하고 넘어간다"는 후기 | [하] |
- 문항 설계
  - 차원은 성실·계획성, 외향·주도, 정서안정, 개방·도전, 협력·친화, 윤리·책임 정도로 잡습니다. 현대차의 핵심가치(고객 최우선, 도전적 실행, 소통과 협력, 인재 존중, 글로벌 지향)도 참고합니다.
  - 표현만 바꾼 일관성 문항 쌍을 약 40쌍 넣습니다. Ⅰ-Ⅱ 사이와 Ⅱ 내부에 배치하고, 역문항을 섞습니다.
  - 사회적 바람직성(거짓말 척도) 문항을 약 15개 넣습니다. 실제 HMAT에 이런 문항이 있는지는 확인되지 않았으므로 [하]입니다.
- 3회분 각각 독립 세트로 만들되, 문항의 60% 이상은 회차마다 새로 씁니다.
- 실제 시험은 결과를 알려주지 않습니다. 모의고사는 다음을 참고용으로 보여 줍니다: 일관성 지수, 무응답 수, 극단 응답 비율, 바람직성 경고, 차원별 프로파일. 규준(norm)이 없다는 점을 화면에 명시합니다.

## 5. 인터페이스 흐름 (적성 세션)
1. **메인 [모의]**: 회차(1·2·3회), 유형(하반기형이 기본, 상반기형 선택 가능), 세션(적성/인성), 모드를 고릅니다. 모드는 실전(모든 제약 적용)과 연습(일시정지·해설 가능) 두 가지입니다.
2. **사전점검 [하]**: 실제로는 시험 전날까지 PC 환경과 접속을 점검합니다. 모의에서는 브라우저, 해상도(1280px 이상 권장), 전체화면 전환 테스트를 하는 체크 화면으로 대신합니다.
3. **체크인·감독 안내 [하~중]**: 실제 체크인은 약 1시간 걸리고 카메라 2대(웹캠과 휴대폰)를 씁니다. 모의에서는 다음 항목을 체크리스트로 보여 줍니다: 휴대폰 전원 끄기, 주변 정리, 360도 방 촬영, 연습장(L자 투명파일) 앞뒷면 보여주기. 웹캠은 사용자가 원할 때 로컬 미리보기만 하고 녹화나 전송은 절대 하지 않습니다. 실전 모드에서도 이 단계는 건너뛸 수 있습니다.
4. **응시자 정보 [하]**: 가상의 수험번호와 성명을 표시합니다.
5. **전체 유의사항**: 다음을 안내하고 시작 버튼을 둡니다. 영역마다 시간이 따로 있음, 끝난 영역으로 돌아갈 수 없음, 계산기·메모장 없음(기본 설정), 오답 감점 없음(비공식).
6. **영역 안내 화면 [하]**: 영역명, 문항 수, 제한시간을 보여 주고 시작 버튼을 둡니다. 이 화면은 해당 영역 시간에 포함하지 않습니다.
7. **문항 화면**
   - 헤더: 영역명, 진행(n/15), **남은 시간 MM:SS**, 수험번호·성명
   - 본문: 긴 지문(언어·정보추론)은 지문을 왼쪽, 문항과 선지를 오른쪽에 두는 분할 화면. 짧은 문항은 한 열.
   - 선지 ①~⑤: 클릭하면 선택, 다른 선지를 클릭하면 바뀜
   - 하단: 이전/다음 버튼, 문항 번호 팔레트(응답한 문항은 채워 표시, 검토 표시 문항은 별도 표시), [영역 종료] 버튼
   - 남은 시간이 5분이면 주황, 1분이면 빨강으로 경고
8. **영역 종료**
   - 시간이 0이 되면 자동으로 종료하고 다음 영역 안내로 넘어갑니다.
   - 조기에 종료하면 확인 모달을 띄워 미응답 수를 경고합니다. 남은 시간은 다음 영역으로 넘어가지 않습니다.
   - 종료한 영역은 잠깁니다.
9. **도식이해**: 먼저 규칙 숙지 화면이 **4분** 카운트다운과 함께 나옵니다. 시간이 끝나면 자동으로 문항 화면(12분)으로 넘어갑니다. 문항을 푸는 동안 규칙표를 볼 수 있는지는 확인되지 않았습니다. 기본은 접이식 참조 패널로 볼 수 있게 하고, 엄격 모드에서는 숨깁니다.
10. **종료**: 실제 시험처럼 "응시가 완료되었습니다"를 띄운 뒤 연습장 지우기 확인 단계(시뮬레이션)를 거칩니다. 그다음 [모의] 결과 화면을 보여 줍니다: 영역별 정답 수, 하위유형별 정답률, 문항별 소요시간, 해설.

## 6. 인터페이스 (인성 세션)
- 안내 화면에서 문항 수, 110분, 응답 방법을 알리고 예시 묶음 1개를 보여 줍니다.
- **인성Ⅰ 화면**: 한 페이지에 3묶음을 둡니다. 각 진술 행에는 7점 라디오 칸, 그리고 [가] [멀] 칸이 있습니다. 묶음 안에서 [가]와 [멀]은 각각 1개만 고를 수 있고 같은 진술에 겹칠 수 없습니다. 모두 응답해야 [다음]이 켜집니다. 페이지 제한시간이 끝나면 자동으로 넘어갑니다.
- **인성Ⅱ 화면**: 한 페이지에 10문항, 각 문항에 [예] [아니오]를 둡니다.
- 상단에 전체 남은 시간, 페이지 남은 시간, 진행률(응답 수/전체)을 표시합니다. 뒤로 가기 버튼은 두지 않습니다.
