# matjip: 평점·리뷰 종합 맛집 추천기

음식/디저트 이름과 지역을 넣으면 여러 출처의 평점·리뷰·웨이팅 정보를 합쳐 네 가지 목록을 만듭니다.

| 카테고리 | 기준 |
|---|---|
| 웨이팅 무관 · 맛 최우선 | 맛 점수 순 |
| 웨이팅 무관 · 맛+분위기 | 맛·분위기 가중 기하평균 순. 맛·분위기 모두 후보군 중간(40) 이상인 곳만 |
| 웨이팅 적음/없음 · 맛 최우선 | 웨이팅 추정이 "거의 없음/짧음"이고 신뢰도 중간 이상인 곳 중 맛 점수 순 |
| 웨이팅 적음/없음 · 맛+분위기 | 위 두 조건을 모두 만족하는 곳 중 맛+분위기 순 |

데이터는 세 갈래로 들어옵니다.

1. **공식 API**: 카카오 로컬(후보 찾기), Google Places(참고 평점). 약관이 허용하는 범위에서만 씁니다.
2. **브라우저 모드**: 네이버 플레이스·카카오맵 공개 페이지를 내 PC 브라우저로 화면 그대로 읽습니다.
   별점, 키워드 리뷰("음식이 맛있어요" 수), 방문자 리뷰의 **대기 시간 태그**가 여기서 나옵니다.
   Playwright 자동 실행, 또는 Claude(데스크톱 앱 / Claude in Chrome)가 대신 읽는 방식 중에서 고릅니다.
3. **수동 CSV**: 직접 확인한 별점, 캐치테이블·블루리본·미쉐린, 실시간 대기 팀 수 등.

## 빠른 시작

```bash
git clone <이 저장소> && cd claude/matjip_finder
python -m matjip 소금빵 --demo        # 설치·키 없이 가상 데이터로 결과 형식 확인
```

실제 검색은 아래 중 **하나 이상**이 필요합니다.

| 방법 | 준비물 | 얻는 것 |
|---|---|---|
| 카카오 로컬 API | `KAKAO_REST_API_KEY` | 후보 목록, 카카오맵 주소 (평점은 없음) |
| 브라우저 모드 (Playwright) | `pip install playwright` + `python -m playwright install chromium` | 네이버·카카오 별점, 키워드, 대기시간 태그, 리뷰 |
| 브라우저 모드 (Claude) | Claude 유료 플랜 + Claude Code(데스크톱 앱 또는 CLI) | 위와 같음. Claude가 브라우저를 대신 조작 |
| 수동 CSV | 직접 조사 | 무엇이든 |

**권장 조합: 카카오 키 + 브라우저 모드.** 카카오 API가 후보와 카카오맵 주소를 주고, 브라우저 모드가 상위 후보만 자세히 읽습니다.

```bash
export KAKAO_REST_API_KEY=...            # Windows PowerShell: $env:KAKAO_REST_API_KEY="..."
python -m matjip 소금빵 --area 성수동 --browser playwright
```

## 설치

Python 3.10 이상이 필요합니다. 기본 기능은 표준 라이브러리만 씁니다.

```bash
cd matjip_finder
pip install -e .                 # 어디서든 `matjip` 명령 사용 (선택)

python -m playwright install chromium
```

## API 키

| 환경변수 | 발급처 | 이 프로그램에서의 쓰임 |
|---|---|---|
| `KAKAO_REST_API_KEY` | Kakao Developers → 앱 생성 → REST API 키 (카카오맵 사용 설정) | 후보 찾기와 카카오맵 주소. 결과는 실행 중 메모리에서만 씁니다 |
| `GOOGLE_MAPS_API_KEY` | Google Cloud 콘솔 → Places API (New) | 기본: 최종 추천된 가게 옆에 **Google Maps 평점을 참고로 표시**만 함. `--google-scoring`을 주면 후보 찾기·점수에도 반영 |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | NAVER Developers (2026-07-30 이후 신규 신청 중단, 기존 키는 2027-06-30까지) | 기본으로 쓰지 않음. `--sources naver`를 직접 적을 때만 사용 |

API를 이렇게 제한해 쓰는 이유는 [약관과 법적 위험](#약관과-법적-위험)에 정리했습니다.
네이버 신규 키는 NAVER API HUB(네이버 클라우드)에서 발급되는데, 호스트와 헤더가 달라 이 프로그램은 지원하지 않습니다.

## 사용법

### 1. API만으로 실행

```bash
python -m matjip 소금빵 --area 성수동
python -m matjip 평양냉면 --area 을지로 --format markdown --top 5
```

카카오 키만 있으면 후보는 나오지만 평점이 없어 순위가 거의 매겨지지 않습니다. 브라우저 모드나 CSV를 함께 쓰세요.

### 2. 브라우저 모드 A: Playwright (자동)

```bash
python -m matjip 소금빵 --area 성수동 --browser playwright
python -m matjip 소금빵 --area 성수동 --browser playwright --browser-max 5 --save-browser-results 성수_소금빵.json
```

진행 순서:

1. 카카오 API(있으면)로 후보를 모아 1차 점수를 매기고, 맛 점수 상위 `--browser-max`곳(기본 8, 최대 15)을 고릅니다.
2. 브라우저 창이 뜹니다. 로그인 정보 없는 새 창입니다.
3. 네이버: `m.place.naver.com/restaurant/list?query=성수동 소금빵` 목록 한 번으로 가게 id를 찾습니다. 각 가게의 방문자 리뷰 페이지를 열어 다음을 읽습니다.
   - 별점
   - 방문자·블로그 리뷰 수
   - "이런 점이 좋았어요" 키워드 수
   - 리뷰 10개와 각 리뷰의 대기 시간 태그
4. 카카오: 카카오 API가 준 `place.map.kakao.com/<id>` 페이지에서 다음을 읽습니다.
   - 별점, 후기 수
   - 추천 포인트(맛·분위기 등)
   - 보이는 후기 3개
5. 수집한 값을 합쳐 최종 순위를 출력합니다.

카카오 키 없이 실행하면 네이버 목록 상위 가게를 후보로 씁니다. 카카오 페이지는 주소를 모르므로 건너뜁니다.

코드로 강제하는 안전장치:

- 로그인 정보·쿠키가 없는 새 브라우저 컨텍스트. 기본은 창을 띄웁니다. 창을 숨기려면 `--browser-headless`를 줍니다.
- 화면 텍스트와 링크 주소만 읽습니다. 네이버·카카오 내부 API 호출, 토큰 재사용, 자동화 흔적 숨기기(stealth)는 하지 않습니다.
- 페이지마다 5~8초 무작위 대기. 가게 8곳이면 대략 2~3분 걸립니다.
- HTTP 403·429, CAPTCHA, "비정상적인 접근" 같은 문구가 보이면 **즉시 전체 수집을 멈추고** 그때까지의 결과로 순위를 냅니다.
- 페이지 이름이 후보와 다르면(동명 가게, 다른 지점) 그 값은 버립니다.

`--save-browser-results FILE`로 저장해 두면, 같은 조건으로 다시 볼 때 `--browser-results FILE`로 브라우저 없이 재사용할 수 있습니다. 사이트에 다시 접속하지 않으니 이쪽을 권장합니다.

### 3. 브라우저 모드 B: Claude가 대신 읽기

Claude가 내 PC의 브라우저를 조작해 같은 정보를 읽습니다. 페이지 구조가 바뀌어도 Playwright 파서보다 덜 깨지지만, 느리고 요금제 사용량을 씁니다.

**준비 (둘 중 하나):**

- **Claude in Chrome (권장)**
  1. Chrome에 **네이버·카카오에 로그인하지 않은 별도 프로필**을 만듭니다.
  2. 그 프로필에만 Claude in Chrome 확장을 설치하고 claude.ai 계정으로 로그인합니다.
  3. 이 저장소 폴더에서 `claude --chrome`으로 Claude Code를 시작합니다. Pro·Max·Team·Enterprise 플랜과 `/login` 로그인이 필요하고, WSL은 지원되지 않습니다.
- **Claude 데스크톱 앱 내장 브라우저**
  1. Code 탭에서 이 저장소 폴더로 세션을 엽니다.
  2. 제목 표시줄의 **Browser**(Ctrl/Cmd+Shift+B)를 엽니다.
  3. ⋮ 메뉴에서 **Keep cookies**를 끄고 **Clear browsing data**를 누릅니다.
  4. 단, 내장 브라우저에서 naver.com이 정책상 막힌다는 보고가 있습니다. 그 경우 네이버는 건너뛰고 카카오만 읽습니다.

**실행:**

```
/matjip-browse 소금빵 성수동
```

저장소에 포함된 프로젝트 스킬(`.claude/skills/matjip-browse`)이 아래 과정을 자동으로 진행합니다.

1. `--browser-plan`으로 작업 파일을 만듭니다.
2. 사이트 접근 승인 카드가 뜨면 사용자가 직접 승인합니다.
3. Claude가 공개 페이지를 읽어 결과 JSON을 쓰고, 최종 추천을 출력합니다.

이 스킬은 JavaScript 실행, 네트워크 요청 읽기, 폼 입력, 일괄 실행 도구를 쓰지 못하게 막아 둡니다.

**스킬 없이 수동으로 할 때:**

```bash
python -m matjip 소금빵 --area 성수동 --browser-plan ./browse
# browse/prompt.md 내용을 Claude에게 붙여넣는다. Claude가 browse/browser_results.json을 쓴다.
python -m matjip 소금빵 --area 성수동 --browser-results browse/browser_results.json
```

**휴대폰에서 원격 실행:** PC에서 `claude remote-control --chrome`을 띄워 두면 Claude 앱(Code 탭)에서 세션을 골라 `/matjip-browse 소금빵 성수동`을 보낼 수 있습니다. PC는 켜져 있어야 합니다.

### 4. 수동 CSV

[`examples/manual_template.csv`](examples/manual_template.csv)를 복사해서 씁니다. 헤더 순서는 상관없고, 없는 값은 비워 둡니다.

| 컬럼 | 의미 |
|---|---|
| `name` (필수), `address`, `lat`, `lng` | 가게 정보. 체인점은 좌표를 넣어야 다른 지점과 섞이지 않습니다 |
| `<플랫폼>_rating`, `<플랫폼>_count`, `<플랫폼>_scale` | 예: `kakao_rating`, `naver_count`, `catchtable_rating`. 만점 기본값은 5, `diningcode`는 100 |
| `taste_votes`, `mood_votes`, `keyword_review_total` | 키워드 리뷰. 맛 관련 득표, 분위기 관련 득표, 기준 수(방문자 리뷰 수 등) |
| `waiting_minutes` | 직접 확인한 평균 웨이팅(분). 넣으면 추정 대신 이 값을 씁니다 |
| `live_waiting_teams`, `observed_at` | 캐치테이블·테이블링 등에서 직접 본 실시간 대기 팀 수와 그 시각 |
| `reservable` | true/false |
| `awards` | `\|`로 구분. 예: `블루리본 2\|미쉐린 빕구르망` |
| `reviews` | `\|`로 구분한 리뷰 원문 |

```bash
python -m matjip 소금빵 --area 성수동 --manual 내가_본_평점.csv --browser-results 성수_소금빵.json
```

### 자주 쓰는 옵션

| 옵션 | 설명 |
|---|---|
| `--top N` | 카테고리별 추천 수 (기본 3) |
| `--format text\|markdown\|json` | 출력 형식 |
| `--browser-max N` | 브라우저로 볼 가게 수 (기본 8, 최대 15) |
| `--browser-sites naver,kakao` | 브라우저로 볼 사이트 |
| `--analyzer claude` | 리뷰 맛·분위기·웨이팅 판정에 Claude 사용 (`ANTHROPIC_API_KEY`) |
| `--google-scoring` | Google 평점을 점수에 반영 (약관 회색지대) |
| `--no-dish-filter` | 요청 메뉴 언급이 없는 가게도 순위에 포함 |
| `--lat/--lng/--radius` | 검색 중심과 반경 |

## 결과 읽는 법

```
[웨이팅 적음/없음 · 맛 최우선]
1. 구름소금빵 성수점 — 서울 성동구 …
   맛 78 · 분위기 41 · 맛+분위기 60 · 웨이팅 거의 없음(신뢰도 높음) · 근거량 높음
   평점: 네이버 4.61(1,284) · 카카오 4.3(1,284)
   네이버 키워드: 맛 812 · 분위기 0 / 기준 1,284
   리뷰 대기시간 태그: 바로 입장 18, 10분 이내 2
   > + 오픈 직후에 가서 갓 나온 소금빵 샀어요 …
   [Google Maps] 4.5 (2,100) https://maps.google.com/?cid=…
```

- **점수(0~100)는 이번 후보군 안의 상대 순위**입니다. 플랫폼마다 평점 분포가 달라서, 원점수를 평균하지 않고 플랫폼 안에서 순위로 바꾼 뒤 합칩니다.
- **웨이팅**은 아래 신호를 합친 추정입니다. 신뢰도가 "낮음"이면 웨이팅 적은 곳 목록에서 뺍니다.
  - 실시간 대기 팀 수 (있으면 가장 크게 반영)
  - 네이버 방문자 리뷰의 대기 시간 태그 분포
  - 리뷰 문장 속 "웨이팅 1시간", "바로 입장" 같은 언급
- `[Google Maps]` 줄은 참고용입니다. 점수에는 쓰지 않습니다 (`--google-scoring` 제외).

## 점수 계산 방식

1. **평점 신호**
   - 플랫폼별로 베이지안 평균(가상 리뷰 15개)에서 표준오차 1배를 뺀 보수적 추정치를 구합니다.
   - 이 값을 플랫폼 안에서 백분위로 바꾸고, `플랫폼 가중치 × log(평점 수)`로 가중 평균합니다.
   - 리뷰 4개짜리 5.0점이 리뷰 400개짜리 4.5점을 이기지 못하게 하려는 장치입니다.
2. **맛 점수** = 평점 신호 45% + 리뷰 텍스트 맛 긍정률 35% + 키워드 리뷰 맛 득표율 20%.
   - 키워드 득표율의 예: "음식이 맛있어요"·"빵이 맛있어요" 득표 ÷ 방문자 리뷰 수. 카카오는 추천 포인트 "맛" ÷ 후기 수입니다.
   - 득표율은 플랫폼별로 구해 평균합니다.
   - 블루리본·미쉐린은 1건당 +4점(최대 +8).
3. **분위기 점수** = 리뷰 텍스트 분위기 긍정률 60% + 분위기 키워드 득표율 40%. "인테리어가 멋져요", "차분한 분위기예요", 카카오 "분위기" 같은 키워드가 해당합니다.
4. **맛+분위기** = 가중 기하평균(맛 0.55, 분위기 0.45). 한쪽만 뛰어난 곳이 위로 오지 않게 합니다.
5. **웨이팅 지수**는 0~1로 나오며 등급은 이렇습니다: 거의 없음 (<0.2) / 짧음 (<0.4, 약 15분) / 보통 (<0.65, 약 40분) / 김.
   - 대기시간 태그는 대표 분으로 바꿔 평균합니다: 바로 입장 0, 10분 이내 5, 30분 이내 20, 30분 이상 45, 1시간 이상 80, 2시간 이상 140.
   - 태그가 적으면 가중치를 줄입니다.
   - 임계값은 실제 대기시간 데이터로 보정하지 않은 휴리스틱이며, [`matjip/config.py`](matjip/config.py)에서 바꿀 수 있습니다.

## 약관과 법적 위험

이 프로그램은 개인이 자기 PC에서 소량으로 쓰는 것을 전제로 합니다. 법률 자문이 아닙니다.

법적 판단의 근거:

- **형사:** 공개 페이지를 일반 브라우저로 읽는 것은 정보통신망 침입으로 보기 어렵다는 판례가 있습니다(대법원 2021도1533, 2023도1086). 반대로 CAPTCHA나 보호조치를 우회하면 침입이 될 수 있습니다(대법원 2021도5555). 그래서 이 프로그램은 차단 신호가 보이면 멈춥니다.
- **민사:** 경쟁 업체가 영업에 쓴 크롤링은 손해배상으로 이어졌습니다(서울중앙지법 2018가합508729, 10억 원). 개인의 비상업 이용은 저작권법 제94조가 준용하는 사적이용 조항(제30조)과, 부정경쟁방지법 파목의 "자신의 영업을 위하여" 요건 때문에 상대적으로 위험이 낮습니다.
- 결과를 다시 배포하거나 상업적으로 쓰지 마세요.

## Claude 분석기 (`--analyzer claude`)

사전 기반 분석은 반어("맛있긴 한데 다시는 안 감"), 비교("옆집보다 별로"), 외국어 리뷰를 놓칩니다. `--analyzer claude`는 가게마다 리뷰 묶음(최대 40건)을 Claude에 보내 맛·분위기 점수와 웨이팅 등급을 JSON으로 받습니다.

- **Claude로 보내는 글은 두 종류뿐입니다.** 직접 입력한 리뷰(CSV)와 브라우저 모드로 읽은 플레이스 리뷰입니다. 네이버 API 텍스트와 Google 콘텐츠는 약관상 보내지 않습니다.
- 기본 모델은 [`matjip/llm_analyzer.py`](matjip/llm_analyzer.py)의 `DEFAULT_MODEL`이며 `--claude-model`로 바꿉니다.
- 오류가 나거나 Claude가 거절하면 사전 분석 결과를 그대로 씁니다.

## 테스트

```bash
cd matjip_finder && python -m pytest
```

실제 사이트와 API는 호출하지 않습니다. 브라우저 파서는 `tests/fixtures/`의 페이지 텍스트로 검증합니다. 이 텍스트는 2025~2026년 실제 화면의 라벨·줄 구조를 따르되, 가게·리뷰·닉네임은 지어낸 값입니다.

## 알려진 한계

- **실제 사이트·API로는 검증하지 못했습니다.** 개발 환경에서 네이버·카카오 접속이 막혀 있었습니다. 파서는 공개 저장소에 남은 2025~2026년 페이지 스냅샷 구조를 기준으로 썼습니다.
  - 첫 실행에서 값이 비면 출력의 `[경고]`를 확인하세요. 네이버 페이지 해석이 연속 2번 실패하면 네이버 수집을 스스로 멈춥니다.
- **2026-07-09 별점 재공개 이후의 네이버 화면 텍스트는 확인하지 못했습니다.** 머리말에 "별점" 다음 숫자가 있을 때만 읽고, 없으면 별점 없음으로 둡니다. 리뷰 카드 안의 별점은 가게 별점으로 쓰지 않습니다.
- **네이버 대기시간 태그는 치우쳐 있습니다.** 한 표본에서 88%가 "바로 입장"이었고, 태그가 없는 리뷰도 많습니다. 실시간 대기 정보가 아니므로 요일·시간대 차이는 반영하지 못합니다.
- **카카오는 PC 홈 화면 기준으로 후기 3개만 읽습니다.**
- **블로그·리뷰에는 체험단·협찬 글이 섞입니다.** 협찬 표기가 보이는 글만 가중치를 낮춥니다.
- **가중치·임계값은 판단값입니다.** 맛 점수 비율 45/35/20, 플랫폼 가중치, 웨이팅 경계가 여기에 해당하며, 정답 데이터로 튜닝하지 않았습니다.
