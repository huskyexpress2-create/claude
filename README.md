# HMAT 대비 모의고사 (비공식)

현대자동차 HMAT(인성·적성검사) 대비용 **비공식** 연습 모의고사 3회분입니다. 온라인 HMAT 응시 흐름을 브라우저에서 재현합니다.

> 현대자동차·현대자동차그룹과 무관합니다. 실제 시험 화면이나 문항을 복제하지 않았고, 모든 문항은 새로 작성하거나 코드로 생성했습니다. 회사 로고, 서체, 브랜드 색상은 쓰지 않습니다.

## 실행

설치나 빌드 없이 `index.html`을 브라우저(Chrome 권장)로 열면 됩니다. `file://`로 열어도 동작합니다.

```bash
# 로컬 서버로 열고 싶다면
npx serve .        # 또는 python3 -m http.server
```

## 구성

| 검사 | 영역 | 문항 / 시간 | 근거 수준 |
|---|---|---|---|
| 적성 | 언어이해 | 15문항 / 20분 | 중 (2025 하반기 후기) |
| 적성 | 논리판단 | 10문항 / 15분 | 중 |
| 적성 | 정보추론(자료해석) | 15문항 / 20분 | 중 |
| 적성 | 도식이해 *(하반기형)* | 규칙 숙지 4분 + 8문항 / 12분 | 하 (단일 후기) |
| 적성 | 공간지각 *(상반기형)* | 10문항 / 15분 | 하 (2026 상반기 후기, 시간은 추정) |
| 인성 | Ⅰ부 | 3진술 묶음 52개: 진술별 척도 + 가깝다/멀다 선택 | 중 |
| 인성 | Ⅱ부 | 단문 300문항 | 하 |

- 하반기형은 도식이해, 상반기형은 공간지각을 출제합니다. 5영역 전체를 고를 수도 있습니다.
- 회차마다 적성 58문항(5영역 기준)과 인성 456진술이 들어 있습니다.
- 2026 하반기 실제 구성은 확인되지 않았습니다. 조사 근거와 한계는 [`docs/research-spec.md`](docs/research-spec.md)와 [`docs/research-critic.md`](docs/research-critic.md)에 정리했습니다. 앱 상단의 "시험 구성·근거" 버튼으로도 볼 수 있습니다.

## 재현한 응시 흐름

- **사전 점검과 감독 확인(실전 모드)**: 브라우저, 해상도, 전체화면을 점검하고 감독 체크리스트를 확인합니다. 카메라 미리보기는 선택 사항이며, 영상은 녹화하거나 전송하지 않습니다.
- **영역별 시간**: 영역마다 타이머가 따로 돌고, 시간이 끝나면 자동 제출됩니다. 끝난 영역으로는 돌아갈 수 없습니다.
- **영역 안 이동**: 문항을 자유롭게 오갈 수 있습니다. 오른쪽 OMR형 답안 표기란, 하단 문항 번호 팔레트, 검토 표시를 씁니다.
- **도식이해**: 4분간 규칙표를 숙지한 뒤 문항이 시작됩니다. 풀이 중 규칙표를 볼 수 있게 할지 숨길지 설정할 수 있습니다.
- **인성검사**: Ⅰ부와 Ⅱ부에 각각 제한시간이 있고 페이지별 제한시간도 있습니다. 이전 페이지로 돌아갈 수 없습니다.
- **실전 모드**: 전체화면을 유지해야 하고, 탭을 전환하면 이탈 기록이 남습니다. 우클릭과 복사가 막히며 일시정지할 수 없습니다.
- **연습 모드**: 일시정지와 문항별 정답 확인이 가능합니다.
- **결과 화면**
  - 적성: 영역별 정답 수, 유형별 정답률, 문항별 소요시간, 해설을 보여 줍니다.
  - 인성: 일관성 지수, 가/멀 선택과 척도 응답의 모순, 극단 응답 비율, 과장 응답 경향, 차원별 프로파일을 보여 줍니다. 규준이 없는 참고 지표입니다.

출처마다 엇갈리는 항목은 홈 화면 설정에서 바꿀 수 있습니다. 계산기·메모장 제공 여부, 인성 척도(5점/7점), Ⅱ부 응답 방식, 인성 시간 배분, 오답 감점, 감독 재점검 시뮬레이션, 영역 구성 비공개(상·하반기형 무작위), 실전 모드 전체화면 강제가 해당됩니다.

### 다른 사람에게 풀게 할 때

- claude.ai 아티팩트로 게시할 수 있습니다. `node tools/build-artifact.mjs <출력.html>`이 아티팩트용 진입 파일을 만들고, 함께 올릴 CSS·JS·데이터 파일 목록을 출력합니다. 아티팩트 화면에서는 인쇄 창과 카메라를 쓸 수 없으므로 연습장 인쇄 링크와 카메라 미리보기 대신 안내 문구가 나옵니다.

- 저장소의 `index.html`을 웹에 올리거나(GitHub Pages 등) ZIP으로 받아 열면 됩니다. 응시자는 PC Chrome을 권장합니다.
- 결과와 응시 기록은 **응시자의 브라우저에만** 저장됩니다. 결과를 받으려면 응시자가 결과 화면을 캡처해 보내야 합니다.
- 정답이 웹페이지 파일 안에 들어 있으므로, 성실한 연습용입니다. 평가나 선발 도구로는 맞지 않습니다.

## 문항 제작과 검증

- **언어이해·논리판단·정보추론**: 회차와 영역마다 새로 작성했습니다. 이어서 정답을 모르는 상태의 풀이자와 검수자 2명이 각각 독립적으로 풀었습니다. 정답이 다르거나 결함이 지적된 문항은 수정한 뒤 다시 검증했습니다. 논리 퍼즐은 브루트포스로 해가 하나뿐인지 확인했고, 자료해석 수치는 코드로 검산했습니다. 자료의 수치는 모두 가상입니다.
- **공간지각·도식이해**: 시드를 고정한 생성기로 만들었습니다. 정답이 하나뿐인지는 시뮬레이션으로 검증했습니다. 공간지각은 투상, 전개도 접기(24가지 회전 전수 검사), 종이 접기 반사 계산을 썼고, 도식이해는 변환 시뮬레이터를 썼습니다. 이어서 독립 검수자가 렌더링된 그림만 보고 다시 풀었습니다. 공간지각 오답은 정답에서 한 곳만 바꾼 변형으로만 채우지 않습니다. 생성기는 그림을 풀지 않고 고르는 방법이 통하지 않는지 검사합니다. 정답이 선지 집합의 중심(다른 선지와의 차이 합이 가장 작은 선지)이 아니어야 하고, 차이 합이 가장 큰 선지도 아니어야 합니다. 자리별 다수결로 맞춘 조합도 정답과 달라야 합니다. 블록 개수 문항의 숫자 선지는 실제로 나올 법한 잘못 센 값으로 만들고, 정답 위치는 회차마다 다르게 둡니다.
- **인성검사**: 6개 차원 진술문, 일관성 쌍, 과장 응답 탐지 문항으로 은행을 만들었습니다. 회차마다 시드를 고정해 서로 다르게 구성합니다.

- **최종 검수**: 처음 보는 풀이자가 텍스트 120문항을 한 번 더 풀었고, 정답키와 어긋난 문항은 0개였습니다. 작성 단계에서 회차마다 정답 번호 순서가 비슷하게 나와 선지를 재배열했고, 재배열 후 해설의 번호 대응도 독립 검수했습니다.

```bash
node tools/validate.mjs           # 데이터 검증
node tools/e2e.mjs                # 사용자 흐름 E2E 테스트(전역 playwright 필요)
node tools/gen-spatial.mjs        # 공간지각 데이터 재생성
node tools/gen-diagram.mjs        # 도식이해 데이터 재생성
```

## 한계

- **공간지각 찍기 단서 점검**: 독립 검수자가 '그림을 풀지 않고 선지 생김새만으로 정답을 고를 수 있는가'를 여러 차례 감사했고, 그에 따라 오답 구성을 바꿨습니다. 선지 중심(medoid)·위치별 다수결·회전·반전 묶음·부분집합·숫자 양 끝/가운데 단서가 대상이었습니다. 남은 약한 단서는 두 가지입니다. 하나는 투상도→입체 문항에서 정답이 '투상도별 다수 묶음'에 모두 속한다는 점입니다. 이를 이용하려면 다섯 선지의 투상도를 모두 구해야 하므로 실제로 푸는 것과 수고가 같습니다. 다른 하나는 블록 개수 문항에서 '바닥 직육면체 부피 − 오답 = 정답'이 성립하는 우연한 쌍이 1~2건 있다는 점입니다.

- 실제 HMAT 화면은 공개된 스크린샷이 없습니다. 근거가 있는 동작은 그대로 구현했고, 나머지 배치는 국내 온라인 CBT의 일반형으로 근사했습니다. 근거가 있는 동작은 영역별 독립 타이머, 영역 안 자유 이동, 이전 영역 복귀 불가, 도식 숙지 시간, 인성 Ⅰ·Ⅱ부 구조입니다.
- 난이도는 후기의 정성 평가만 참고했습니다. 실제 시험과 체감 난이도가 다를 수 있습니다.
- 응답과 기록은 브라우저 localStorage에만 저장됩니다.
